Статическая страница авторазборки. Публикуется через GitHub Pages.

| | Адрес |
|---|---|
| 🧪 Тест (все правки сначала здесь) | https://rbazenov.github.io/narazborku-landing-stage/ |
| 🚀 Прод (боевая страница) | **https://finklass.online/** |

Цены, наличие, **личный кабинет и оформление заказа** работают через магазин
(админка) — см. разделы «Связка с магазином» и «Личный кабинет и заказы»
в [инструкции](docs/LANDING-WORKFLOW.md).

## Как вносить правки

1. Правки делаем и проверяем на **тестовом** адресе.
2. В прод переносим только проверенное — отдельной командой.

```bash
bash scripts/stage.sh "что изменили"      # опубликовать в тест
bash scripts/promote.sh --yes             # перенести проверенное в прод
```

Прод **не обновляется** обычной отправкой правок: рабочая копия настроена так,
что стандартный `git push` уходит в тестовый репозиторий.

Полное описание процесса, защита от случайной публикации и частые вопросы:
**[docs/LANDING-WORKFLOW.md](docs/LANDING-WORKFLOW.md)**

## Состав

| Файл | Что это |
|---|---|
| `index.html` | вся страница: разметка, стили и скрипты в одном файле (334 КБ) |
| `brand/` | логотипы, иконки, картинка для соцсетей |
| `robots.txt`, `sitemap.xml` | правила для поисковых систем |
| `scripts/stage.sh` | публикация в тест |
| `scripts/promote.sh` | перенос проверенного в прод |
| `scripts/init-remotes.sh` | восстановление доступа к репозиториям (нужен токен) |
